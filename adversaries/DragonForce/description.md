# DragonForce Ransomware

## Overview

DragonForce is a ransomware operation operating under a Ransomware-as-a-Service (RaaS) model.  
The group provides ransomware infrastructure to affiliates who conduct the intrusions and deploy the ransomware payload.

The operation emerged around 2023 and targets organizations globally.

## Operational Model

DragonForce operates a white-label ransomware model where affiliates can customize the ransomware payload while using the core infrastructure provided by the group.

Key components include:

- Ransomware builder
- Data leak sites
- Affiliate management panels
- Victim negotiation portals

## Targeted Sectors

The group has targeted multiple industries including:

- Manufacturing
- Technology companies
- Service providers
